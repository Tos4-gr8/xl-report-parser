# Excel Calc v1.0 🧮

Приложение с графическим интерфейсом на `CustomTkinter` для автоматизации расчетов из отчетов в Excel.

## 🚀 Функционал
- Расчет заработной платы по фамилии сотрудника.
- Автоматическая проверка и обработка отчетов (Работа с РТ, Деление паллет, Экспедиция-отгрузка, Перемещения).
- Визуализация данных с помощью графиков `Matplotlib`.

## 📦 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Tos4-gr8/xl-report-parser.git
   ```

2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите приложение:
   ```bash
   python main.py
   ```
