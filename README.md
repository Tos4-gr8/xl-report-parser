# 🇺🇸 English Version

## 📌 Overview

**Excel Salary Calculator** is a desktop application designed to simplify monthly performance-based salary calculations.

The application connects to currently running Excel instances, identifies the required workbooks and worksheets using internal structural markers, extracts performance data for a selected employee, applies predefined calculation rates, and displays the resulting salary information together with statistical visualizations.

---

## 🚀 Key Features

### ⚡ Asynchronous Excel Processing

Heavy Excel operations are executed inside a background worker thread using Python's `threading.Thread`.

This keeps the graphical interface responsive while reports are being scanned and processed.

### 📊 Dynamic Excel Workbook Detection

The application scans active `EXCEL.EXE` instances and searches for relevant workbooks and worksheets using internal structural cell markers.

This eliminates the need to manually specify every workbook path.

### 🔎 Robust Employee Search

Employee data is processed using case-insensitive string matching and whitespace normalization.

This helps handle common formatting differences in 1C-generated reports, such as:

- uppercase/lowercase differences;
- extra spaces;
- inconsistent text formatting.

### 🛡️ Safe Data Processing

The calculation pipeline handles missing rows, empty cells and `NaN` values before performing numerical calculations.

This reduces the risk of runtime errors caused by incomplete or unexpected Excel data.

### 📈 Statistics Visualization

The application includes a dedicated statistics tab with embedded `matplotlib` charts.

The visualization shows the contribution of individual report categories to the calculated income.

## 📦 Installation

### Requirements

Before running the application, make sure that:

- Python 3.10 or newer is installed;
- required Python packages are available;
- the necessary Excel reports can be opened in Microsoft Excel;
- the application is running in an environment compatible with `xlwings` and Excel automation.

### 1. Clone the repository

```bash
git clone https://github.com/Tos4-gr8/xl-report-parser
cd excel-salary-calculator
```

### 2. Create a virtual environment

#### Windows PowerShell

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

#### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start the application

```bash
python main.py
```

Run:


**`Рассчитать З/П`**

The main window displays the calculated salary information.

# 🇷🇺 Русская версия

## 📌 Описание

**Excel Salary Calculator** — настольное приложение для автоматизации расчёта заработной платы на основе показателей производительности.

Программа подключается к открытым экземплярам Excel, находит необходимые книги и листы по внутренним структурным маркерам, извлекает показатели конкретного сотрудника, применяет заданные тарифные ставки и отображает рассчитанные значения вместе со статистикой.

---

## 🚀 Основной функционал

### ⚡ Асинхронная обработка Excel

Тяжёлые операции с Excel выполняются в отдельном фоновом потоке с использованием `threading.Thread`.

Благодаря этому интерфейс приложения остаётся отзывчивым во время поиска и обработки отчётов.

### 📊 Динамическое сканирование Excel

Программа автоматически проверяет запущенные экземпляры `EXCEL.EXE` и ищет необходимые книги и листы по внутренним структурным маркерам.

Пользователю не требуется вручную указывать путь к каждому отчёту.

### 🔎 Устойчивый поиск сотрудника

При поиске используются регистронезависимое сравнение строк и предварительная нормализация пробелов.

Это позволяет корректно обрабатывать распространённые различия в данных, полученных из 1С:

- разные регистры букв;
- лишние пробелы;
- различия в форматировании текста.

### 🛡️ Обработка пропущенных данных

Перед выполнением расчётов программа обрабатывает пустые ячейки, отсутствующие строки и значения `NaN`.

Это снижает вероятность ошибок при работе с неполными или неожиданно сформированными Excel-таблицами.

### 📈 Вкладка статистики

В приложении предусмотрена отдельная вкладка **`Статистика`** с графиками на базе `matplotlib`.

Она позволяет увидеть распределение рассчитанного дохода между отдельными категориями отчётов.
